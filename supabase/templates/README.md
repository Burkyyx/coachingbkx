# Modèles d'e-mails (français)

À copier dans Supabase : _Authentication → Emails → Templates_.

| Modèle Supabase | Fichier | Objet (Subject) |
|---|---|---|
| Confirm signup | `confirmation.html` | Confirme ton adresse e-mail – Divus |
| Reset password | `recovery.html` | Ton nouveau mot de passe Divus |
| Change email address | `email_change.html` | Confirme ta nouvelle adresse e-mail – Divus |

Les autres modèles (Magic link, Invite user, Reauthentication) ne sont pas utilisés par l'app.
